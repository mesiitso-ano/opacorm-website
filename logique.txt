━━ VUE D'ENSEMBLE ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  But     : Site vitrine de la société Opacorm
            → Présenter la marque et ses produits
            → Permettre le téléchargement des apps (CONEP APK + Windows)
            → Point de contact (email)

  Domaine : opacorm.com
  Hébergement : Vercel (déploiement auto depuis GitHub)
  Repo GitHub : github.com/mesiitso-ano/opacorm-website

  Ce projet N'inclut PAS :
    - Le backend FastAPI (repo CONEP)
    - L'admin panel (repo CONEP/admin)
    - L'app Flutter (repo CONEP/frontend)

━━ DESIGN ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Fond        : Blanc (#ffffff) — pas sombre comme l'ancienne version
  Typographie : Inter (Google Fonts)
  Couleur     : Violet (#7c3aed) comme couleur principale
  Navigation  : Fullpage — une section visible à la fois, pas de scroll
  Transitions : fade + slide (350ms cubic-bezier)
  Dots nav    : barre de points à droite (desktop uniquement)

━━ NAVIGATION ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Méthodes de navigation :
    - Molette souris (wheel)
    - Swipe tactile (touch)
    - Flèches clavier (↑ ↓, PageUp, PageDown)
    - Clics sur les dots (droite)
    - Clics sur les boutons data-goto
    - Liens de la navbar (data-section)

  Cooldown molette : 800ms (évite les sauts de pages multiples)
  Swipe minimum : 50px de déplacement

━━ DÉPLOIEMENT ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Étapes :
  1. Repo GitHub : github.com/mesiitso-ano/opacorm-website ✅ (créé)
  2. Vercel → New Project → importer opacorm-website
  3. Root directory : / (racine)
  4. Framework : Other (site statique)
  5. Deploy
  6. Settings → Domains → Ajouter opacorm.com + www.opacorm.com
  7. Vercel donne un CNAME → configurer sur LWS :
       A     @    76.76.21.21        (IP Vercel)
       CNAME www  cname.vercel-dns.com
